# Fieldnotes design decisions

UI UX Pro Max was consulted for educational products and the Next.js stack. Its generic education profile suggested childlike claymorphism; this conflicts with the requested restrained university interface. The academic retry matched Swiss Modernism, serif accents, content hierarchy, search and reduced motion. We apply the LMS industry reasoning rule `if_content_focused: prioritize-clarity` and `if_mobile: optimize-touch-targets`, with visible course progress and simple navigation.

The bespoke palette pairs forest ink #233c32, paper #f8f9f5, olive #6c7b58 and warm ochre #a35b32. Serif headings and simple sans-serif controls give the collection an editorial identity. There are no fabricated success statistics, marketing quotes, generated biological illustrations, gradients, or decorative looping motion. Source slides provide all scientific graphics.

The installed `emil-design-eng` skill supplies the Emil Kowalski interaction guidance: interruptible spring transitions (stiffness 420, damping 35, mass .7), short opacity changes, tactile button press, hover effects only on pointer devices and reduced-motion support. Flashcard flips initiated from the keyboard are immediate. The selected stage uses a shared spring underline; course filters use spring layout positioning.

No skill named `tasteful` was available after searching the local skill directories, including symlinks. Its requested anti-generic direction is implemented through the explicit design constraints above; no claim is made to have invoked a missing skill.

Playwright CLI was installed locally for QA and its official bundled skill was loaded. See the QA report for actual verification evidence.

Technical references: [Next.js deployment](https://nextjs.org/docs/app/getting-started/deploying), [Tailwind installation](https://tailwindcss.com/docs/installation/framework-guides/nextjs), [Motion accessibility](https://motion.dev/docs/react-accessibility), [Playwright CLI](https://github.com/microsoft/playwright-cli). No external biological references were used.
